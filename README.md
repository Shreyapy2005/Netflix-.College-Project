# 🎬 Netflix Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing Netflix movies and TV shows using data analytics tools. The main objective is to explore the Netflix dataset, identify useful patterns, and present meaningful insights through data analysis and visualization.

The project covers the complete data analytics process using Excel, SQL, Python, and Power BI.

## 🎯 Project Objectives

- Analyze Netflix movies and TV shows.
- Understand the distribution of movies and TV shows.
- Explore content by country, genre, and release year.
- Perform data cleaning and preprocessing.
- Write SQL queries to answer business questions.
- Create visualizations and an interactive Power BI dashboard.
- Generate meaningful insights from the dataset.

## 🛠️ Tools and Technologies

|Tool             | Purpose                                       |
| Microsoft Excel | Data cleaning, analysis                       |
| SQL             | Data querying and analysis                    |
| Python          | Data cleaning, preprocessing, and exploration |
| Power BI        | Interactive dashboard and data visualization  |

## 📂 Project Workflow

1. **Data Collection:** Load the Netflix titles dataset.
2. **Excel Analysis:** Inspect the data, clean records, and explore patterns.
3. **SQL Analysis:** Use SQL queries to answer analytical questions.
4. **Python Analysis:** Clean, transform, and analyze the dataset.
5. **Power BI Dashboard:** Build visualizations to present the findings.
6. **Insights:** Summarize the key observations from the analysis.

## 📊 Key Analysis Areas

- Movies vs. TV Shows
- Content distribution by country
- Netflix titles by release year
- Content ratings and categories
- Popular genres and content types
- Overall content distribution and trends
